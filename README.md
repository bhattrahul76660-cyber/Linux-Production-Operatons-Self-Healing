Linux Production Operations & Self-Healing

A practical Linux production operations project built with Bash scripting.

- Performs automated system health monitoring for CPU, memory, disk, network, and critical services.
- Checks HTTP, DNS, FTP, time synchronization, logs, firewall, and SELinux health.
- Includes self-healing automation to detect failed services and attempt automatic recovery.
- Generates operational logs and health reports for troubleshooting and monitoring.
- Designed to simulate real-world Linux Cloud Support / Production Operations tasks.
- Technologies: Linux, Bash, systemd, networking, SELinux, firewalld, and troubleshooting.
